# stm32f405-flight-controller
This project is a STM32F405 based flight controller. The objective of this personal project is to learn how to design circuits, printed circuit boards (PCB) and other electrical engineering principles. The main focus is hardware design and the software aspect will be minimal. In addition to a self-made PCB, fusion360 will be used to 3D print the body of the drone.

Parts Used:
STM32F405 Microcontroller
BMI323 Inertial Measurement Unit
MPL3115A2 Barometer
MIC5365 low-dropout regulator 5V to 3.3V
AP62300 Buck Regulator 7V to 5V
